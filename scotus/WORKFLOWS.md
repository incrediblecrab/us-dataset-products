# workflows

**Objective:** keep every dataset current with no personal device and no person, given a commit every 60 days. The workflow is scheduled at 12:37 UTC so that it starts near 17:00 UTC (12:00 EST, 13:00 EDT), because GitHub starts runs late, often by hours, or drops them. From September 27 to October 15, 2026 GitHub started every one of the 208 scheduled runs of the four dataset pipelines in this account late, by 2.4 to 9.2 hours, and the 18 daily runs scheduled at 14:00 UTC from October 13 by 3.9 to 6.2 hours, so the cron asks for 12:37 UTC to have them start near 17:00 UTC. A run GitHub starts on time starts at 12:37 UTC (7:37 EST, 8:37 EDT).

**Inputs:** the Court's pages and files, the document datasets as the Hub holds them, and the job's OIDC token, which Hugging Face exchanges for a short-lived write token scoped to one dataset when that dataset lists this repository, branch `main` and `scotus-pipeline.yml` as a Trusted Publisher; otherwise the write fails. The trade is retried when GitHub or the Hub answers a server error or drops the connection, as a commit is, and a refusal is raised at once. No secret is used.

**Files:**

- [`scotus-pipeline.yml`](../.github/workflows/scotus-pipeline.yml): `cases` runs `python -m scotus_products.cases run` within 60 minutes, building us-scotus-cases from the document datasets and the docket pages due for a check, then its `verify`; it runs before `sync`, so the two never ask the Court for pages at once, and `sync` runs whether it succeeded or not. `sync` runs `python -m scotus_products run --dataset all` within 290 minutes, keeping 10 minutes for each collection still to come, then `verify` checks each collection the run changed. `continue` starts the next run when `sync` ran out of budget while files remained, or `cases` ran out of budget, and that job fetched something. `inactivity` fails after 50 days without a commit, before GitHub disables every schedule here at 60. It makes no keepalive commit: GitHub [called](https://github.com/ddev/github-action-add-on-test/issues/46) that a Terms violation.
- [`scotus-test.yml`](../.github/workflows/scotus-test.yml): runs the test suite on pushes to `main` and pull requests that change `scotus/` or this workflow, with read-only contents and no OIDC token, so it cannot publish.

GitHub reports a failed scheduled run to whoever last changed its cron, by email if their settings allow. A dispatch (**Run workflow**) takes a collection, a budget, a budget for `cases` (0 skips it) and extra run arguments; with extra arguments it runs only a bounded sync test, skips verify and `cases`, and never starts another run. The root's `.github/` has no README, which GitHub would show instead of the repository's.
